# Thinking with Type, Ellen Lupton — Reading Response

This website is a reading response to Ellen Lupton's *Thinking with Type*, created for Typography & Interaction class.

## About the Reading

*Thinking with Type* is not just a book about fonts, but a book about how to use them. The book is divided into three main chapters: Letter, Text, and Grid. For this project, I selected content mainly from the Letter chapter.

The sections I selected explore the history and development of type, type classification, punctuation, and type on screen. I wrote my own response to each section and used the website design to explore some of the ideas that stood out to me.

One idea that especially influenced my project is that type is not only something we read, but also something we see as a visual form.

## Design Concept

For the design, I wanted the website itself to respond to the ideas in the reading instead of only displaying the text.

The hero section is inspired by the original *Thinking with Type* book cover. I was interested in how the word "type" becomes really large and almost works as an image, while the other information is arranged around it. I used this idea as a reference and interpreted it in my own way.

I also wanted the first screen to feel like the cover of a book. The hero occupies almost the whole screen when the website first opens, and the reader scrolls down to enter the content, almost like opening a book and starting to read.

Throughout the website, I use different colors, typefaces, scale, and positioning to separate Lupton's original text from my own response. I also created type specimens for the Type Classification and Punctuation sections so readers can actually see the differences between typefaces instead of only reading about them.

## Typography & Color

I used Sentient for the main reading and Switzer for my responses. I wanted the original reading and my own voice to feel different, while also choosing typefaces that work well for reading on screen.

I used MediumBlue for the original reading and Salmon for my responses. The two colors create a clear contrast between the two voices. Instead of using a pure white background, I chose Cornsilk to make the website feel warmer and more engaging.

Additional typefaces are used as specimens throughout the website to demonstrate the classifications discussed in the reading.

## How I Made It

The website was built with semantic HTML and CSS.

I used semantic elements such as `article`, `section`, `aside`, `blockquote`, `em`, `strong`, `q`, and description lists to organize the content based on its meaning rather than only its appearance.

Most of the website follows the normal document flow, but the hero uses relative and absolute positioning because I wanted more freedom to arrange the typography like a book cover or poster composition.

I also used CSS variables and relative units such as `rem`, `ch`, and `vh` to create a more consistent type and spacing system.

## Things I Want to Remember

- HTML should describe the meaning and structure of the content, while CSS controls its appearance.
- Type can work as both language and image.
- A typeface choice should consider not only how it looks, but also its history, context, and where it will be used.
- Even small elements such as punctuation can become part of the visual language of a design.
- Not every part of a website needs to be expressive. Keeping the body text simple makes the more experimental typographic moments stand out.
- Relative and absolute positioning can be useful for a controlled composition, but they should have a reason rather than being used for every layout.
- When designing for the web, typography needs to work in a changing space rather than a fixed printed page.
